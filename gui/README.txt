
Ranobes Chapter Finder GUI

HOW TO USE:

1) Install Python (https://python.org)

2) Open this folder

3) Double click build_exe.bat

4) After build finishes you will get:

dist/ranobes_gui.exe

You can run that EXE without Python.

APP FEATURES
- Paste any Ranobes chapter link
- It scans all next chapters automatically
- Saves chapter links to TXT
